Entry for [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) — a complete story told in exactly six words.

## The story

> He came home. Nobody remembered him.

Six words, one life: a long absence, a hopeful return, and the quiet shock of being forgotten by the very place he came back to. Every word earns its place — the setup in the first three, the turn in the last three.

## How to run

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (no trailing newline). The program is deterministic, uses no network, and reads no environment variables or other files.
